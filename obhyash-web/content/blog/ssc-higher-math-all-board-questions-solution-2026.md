# এসএসসি উচ্চতর গণিত বোর্ড প্রশ্ন ও সমাধান ২০২৬: সৃজনশীল (CQ) ও বহুনির্বাচনি (MCQ) পূর্ণাঙ্গ বিশ্লেষণ

উচ্চতর গণিত অনেকের কাছে এসএসসির সবচেয়ে চ্যালেঞ্জিং বিষয়। সেট, ফাংশন, সূচক, লগারিদম, স্থানাঙ্ক জ্যামিতি, ত্রিকোণমিতি — প্রতিটি অধ্যায়ে ধারণা ও গাণিতিক দক্ষতা দুটোই দরকার। ২০২৬ সালের প্রশ্নপত্র বিশ্লেষণ করলে একটা বিষয় পরিষ্কার: যে শিক্ষার্থী ধাপে ধাপে সমাধান লেখে এবং চিত্র আঁকতে পারে, সে এই বিষয়ে সবচেয়ে ভালো নম্বর পায়।

## অধ্যায়ভিত্তিক ডিপ ডাইভ

### সেট ও ফাংশন

**প্রশ্ন:** $A = \{1, 2, 3, 4\}$, $B = \{3, 4, 5, 6\}$ হলে $A \cup B$, $A \cap B$ এবং $A - B$ নির্ণয় করো।

$$A \cup B = \{1, 2, 3, 4, 5, 6\}$$
$$A \cap B = \{3, 4\}$$
$$A - B = \{1, 2\}$$

### লগারিদম

**প্রশ্ন:** $\log_2 8 + \log_3 27 = ?$

$$\log_2 8 = \log_2 2^3 = 3, \quad \log_3 27 = \log_3 3^3 = 3$$
$$\therefore \log_2 8 + \log_3 27 = 3 + 3 = \mathbf{6}$$

### স্থানাঙ্ক জ্যামিতি

**প্রশ্ন:** $(2, 3)$ ও $(8, 11)$ বিন্দু দুটির মধ্যবিন্দু ও দূরত্ব নির্ণয় করো।

মধ্যবিন্দু: $\left(\frac{2+8}{2}, \frac{3+11}{2}\right) = \mathbf{(5, 7)}$

দূরত্ব: $d = \sqrt{(8-2)^2 + (11-3)^2} = \sqrt{36 + 64} = \sqrt{100} = \mathbf{10}$ একক

### ত্রিকোণমিতিক অভেদ

**প্রমাণ করো:** $\sec^2\theta - \tan^2\theta = 1$

$$\sec^2\theta - \tan^2\theta = \frac{1}{\cos^2\theta} - \frac{\sin^2\theta}{\cos^2\theta} = \frac{1 - \sin^2\theta}{\cos^2\theta} = \frac{\cos^2\theta}{\cos^2\theta} = \mathbf{1}$$

## টপ ৫ সাধারণ ভুল

**১. ধাপ বাদ দেওয়া।** উচ্চতর গণিতে প্রতিটি ধাপ নম্বরের অংশ।

**২. চিহ্ন ভুল করা।** ঋণাত্মক সংখ্যার বর্গ, লগের ভিত্তি — এসবে চিহ্ন ভুল সবচেয়ে কমন।

**৩. একক না লেখা।** পরিমিতিতে একক অবশ্যই লিখবে।

**৪. ত্রিকোণমিতিক মান ভুল করা।** $\sin 30° = \frac{1}{2}$, $\cos 60° = \frac{1}{2}$, $\tan 45° = 1$ — মূল মানগুলো নিশ্চিত রাখো।

**৫. স্থানাঙ্ক জ্যামিতিতে চিত্র না আঁকা।** সরলরেখা, ত্রিভুজ — চিত্র আঁকলে ভুল কমে।
